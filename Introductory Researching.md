><details><summary>❓What hash format are modern Windows login passwords stored in?</summary>NTLM</details>

# Manual Pages

&nbsp;










&nbsp;

---
><details><summary>❓SCP is a tool used to copy files from one computer to another. What switch would you use to copy an entire directory?</summary>-r</details>
---
><details><summary>❓fdisk is a command used to view and alter the partitioning scheme used on your hard drive. What switch would you use to list the current partitions?</summary>-l</details>
---
><details><summary>❓nano is an easy-to-use text editor for Linux. There are arguably better editors (Vim, being the obvious choice); however, nano is a great one to start with. What switch would you use to make a backup when opening a file with nano?</summary>-B</details>
---
><details><summary>❓Netcat is a basic tool used to manually send and receive network requests. What command would you use to start netcat in listen mode, using port 12345?</summary>nc -l -p 12345</details>
